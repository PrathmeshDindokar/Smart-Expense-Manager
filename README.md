# Smart Expense Manager

A full-stack expense management application built using Spring Boot, React.js, MySQL, and JWT authentication.

## Features
- User Registration and Login
- JWT Authentication
- Dashboard with Income, Expenses, and Balance
- Add, Edit, and Delete Transactions
- Budget Management
- AI-Powered Financial Insights

## Tech Stack
- Frontend: React.js, JavaScript, CSS
- Backend: Java, Spring Boot
- Database: MySQL
- Authentication: Spring Security, JWT
- Build Tool: Maven

## Project Structure
- smart-expense-manager — Backend
- smart-expense-fronted — Frontend

## How to Run

### Backend
1. Open the backend folder in VS Code.
2. Configure MySQL credentials in `application.properties`.
3. Run the Spring Boot application.

### Frontend
1. Open a terminal in the frontend folder.
2. Run `npm install`.
3. Run `npm run dev`.
